# PRD: Планировщик задач

**Версия документа:** 1.0 · 26 ноября 2026
**Статус:** MVP запущен, ведётся доработка
**Продукт:** [Планировщик задач](https://claude.ai/artifact/Xtd7TAgsD1gyDzuFDLj7ms) — веб-страница (артефакт Claude) + ежедневные push-напоминания

---

## 1. Проблема и цель

Пользователю нужен один удобный инструмент, который:

- собирает **все рабочие и личные задачи** в одном месте;
- ведёт их **ежедневно** — что сделано, что нет;
- **выдаёт результаты исполнения** (итоги дня и недели);
- **напоминает о невыполненных задачах**, в том числе вне приложения.

**Цель MVP:** пользователь каждое утро видит план, в течение дня отмечает выполнение, вечером получает итоги и список хвостов — без ручного подсчёта.

## 2. Пользователь

Один пользователь (владелец), часовой пояс **Asia/Qyzylorda (UTC+5)**, интерфейс на русском. Работает с компьютера и телефона, часть задач — рабочие (комплаенс, документы), часть — личные.

## 3. Ключевые сценарии

1. **Добавить задачу** со сроком (дата + время), категорией, срочностью/важностью и, при необходимости, повтором.
2. **Разбить задачу на подзадачи**, у каждой — свой срок, срочность и статус.
3. **Утром** увидеть, что сделать сегодня и что «на подходе»; получить push-сводку.
4. **В течение дня** отмечать выполнение; видеть подсветку задач, срок которых скоро.
5. **Вечером** увидеть итоги дня и получить push с невыполненным.
6. **Разобрать хвосты**: перенести просроченное на сегодня одной кнопкой.
7. **Приоритизировать** по матрице «срочно / важно».

## 4. Функциональные требования

### 4.1 Задача

| Поле | Обязательно | Описание |
|---|---|---|
| Название | да | до 200 символов |
| Категория | да | «Работа» или «Личное» (переключатель, по умолчанию «Работа») |
| Дата завершения | **да** | срок; у повторяющейся задачи — дата начала |
| Время завершения | **да** | срок в течение дня |
| Срочно | нет | флаг (чекбокс) |
| Важно | нет | флаг (чекбокс) |
| Повтор | нет | один раз / каждый день / по будням / каждую неделю |

- Без даты и времени задача **не сохраняется**: показывается ошибка «Укажите название, дату и время завершения», фокус переходит на пустое поле.
- Редактирование — через ✎ (форма заполняется данными задачи, баннер «Редактирование»).
- Удаление — через ✕, с кнопкой **«Вернуть»** (6 секунд).

### 4.2 Подзадачи (полноценные задачи)

- Подзадача — **такая же задача**: своя категория, дата и время завершения (обязательно), срочность, важность, статус выполнения, подсветка «на подходе» / «просрочено».
- Создание — кнопкой **＋** в строке задачи; форма предзаполняется параметрами родителя, баннер «Новая подзадача для «…» · срок задачи: …».
- Быстрое создание — поле «Быстрые подзадачи» в форме (каждая с новой строки), они наследуют срок и параметры задачи.
- **Вложенность до 3 уровней** (у подзадачи могут быть свои подзадачи).
- **Срок подзадачи не может быть позже срока родителя** — иначе ошибка.
- **Статусы независимы:** задачу можно закрыть при открытых подзадачах и наоборот. Когда закрыта последняя подзадача — подсказка «Все подзадачи выполнены — можно закрыть задачу» (автозакрытия нет).
- У родителя — счётчик «подзадачи 2/3», по нему подзадачи сворачиваются.
- Удаление задачи удаляет **все её подзадачи**; «Вернуть» восстанавливает всё семейство.
- У **повторяющихся** задач подзадач нет (нельзя задать единый срок); задачу с подзадачами нельзя сделать повторяющейся.
- Подзадачи участвуют в матрице, итогах и напоминаниях наравне с задачами.

**Визуальное отличие подзадач:**
- отдельная карточка с рамкой на сером фоне, сдвинутая вправо под родителем; каждый уровень — ещё правее;
- изогнутые линии дерева от задачи к подзадачам (голубые — работа, оранжевые — личное);
- метка «подзадача» перед названием, чуть меньший шрифт и элементы;
- задача, у которой есть подзадачи, — с жирным названием;
- в режиме «По дням» над подзадачей — подпись «↳ <название родителя>».

### 4.3 Списки и режимы

**Режим «Все задачи» (по умолчанию)** — все открытые задачи, сгруппированные по сроку:

| Группа | Условие |
|---|---|
| Просрочено (красным) | срок раньше сегодняшнего дня |
| Сегодня | срок сегодня |
| Завтра | срок завтра |
| На этой неделе | в ближайшие 7 дней |
| Позже | дальше 7 дней |

- Внутри группы — по времени, затем по квадранту матрицы.
- Задача с подзадачами попадает в группу по **самому раннему открытому сроку** в семействе.
- Повторяющаяся задача показывается **один раз** — на ближайшую невыполненную дату.
- В заголовке группы — количество и «на подходе: N».
- Выполненные — внизу, в свёрнутом блоке «Выполненные — N».

**Режим «По дням»** — задачи выбранного дня; навигация ‹ › (и клавиши ← →), кнопка «Сегодня». Для сегодняшнего дня ниже — блок «Хвосты с прошлых дней» с кнопками «На сегодня» и «Перенести все на сегодня».

Выбранный режим запоминается в браузере.

**Фильтры:** Все / Работа / Личное; клик по квадранту матрицы фильтрует список (сброс — «Показать все»).

### 4.4 «На подходе» и напоминания в приложении

- До срока **меньше 24 ч** → жёлтая подсветка строки и метка «⏰ через 3 ч 15 мин».
- До срока **меньше 2 ч** → красная подсветка.
- Срок сегодня прошёл → время красным, «срок прошёл».
- Плашка-напоминание вверху страницы: задачи с прошедшим сроком сегодня + число просроченных за прошлые дни.
- Страница обновляет отсчёт раз в минуту и сама переходит на новый день в полночь.

### 4.5 Матрица Эйзенхауэра

Диаграмма 2×2 в правой колонке (оси: Срочно / Не срочно × Важно / Не важно):

| | Срочно | Не срочно |
|---|---|---|
| **Важно** | Сделать сейчас (красный) | Запланировать (синий) |
| **Не важно** | Делегировать (жёлтый) | Отложить (серый) |

- В квадранте — число открытых задач, «открыто из N», первые 4 названия (подзадачи со значком ↳).
- В режиме «Все задачи» — все открытые задачи и подзадачи; в режиме «По дням» — задачи дня и хвосты.
- У каждой задачи в списке — цветная метка её квадранта.

### 4.6 Итоги исполнения

- **Кольцо дня:** процент выполненного; сегменты «Работа» (синий) и «Личное» (оранжевый); «X из Y выполнено».
- **Полосы:** Работа, Личное, «Срочно и важно» — выполнено / всего.
- **Неделя:** 7 столбиков (клик — переход к дню); дни с невыполненными задачами в прошлом — красные.
- **Показатели:** % выполнения за 7 дней · дней подряд без хвостов · число просроченных.

### 4.7 Push-напоминания (scheduled task)

Ежедневно в **8:47 и 19:47** по времени Кызылорды, push на телефон, без запроса подтверждений.

- **Утро — «План на сегодня»:** задачи и подзадачи со сроком сегодня, сгруппированные по квадрантам, со временем, категорией и «↳ из: родитель»; «На подходе» (срок завтра); «Просрочено» с датами.
- **Вечер — «Итоги дня»:** выполнено X из Y (%), отдельно Работа / Личное / «Сделать сейчас»; невыполненные сегодня (с пометкой «срок прошёл»); что на подходе завтра; число просроченных; короткий совет.
- Сводка только читает базу и ничего в ней не меняет; в конце — ссылка на планировщик.

## 5. Модель данных

Коллекция `tasks` в базе артефакта; один документ = одна задача или подзадача.

```json
{
  "title": "Отправить документы в ЮД",
  "parentId": "tmwx4mg9a7clhy",
  "cat": "work",
  "date": "2026-11-27",
  "time": "10:51",
  "urgent": true,
  "important": true,
  "repeat": "none",
  "doneDates": { "2026-11-27": true },
  "created": "2026-11-26T05:43:14.638Z"
}
```

| Поле | Тип | Значения / смысл |
|---|---|---|
| `title` | string | название |
| `parentId` | string? | id родителя (только у подзадач) |
| `cat` | string | `work` · `pers` |
| `date` | YYYY-MM-DD | срок; у повторяющихся — дата начала |
| `time` | HH:MM | время срока |
| `urgent`, `important` | bool | квадрант матрицы |
| `repeat` | string | `none` · `daily` · `weekdays` (пн–пт) · `weekly` (день недели = день недели `date`) |
| `doneDates` | {дата: bool} | выполнено в день D ⇔ `doneDates[D] === true` |
| `created` | ISO | дата создания |

**Правила:**
- Задача приходится на день D: `repeat = none` → `date == D`; иначе `D >= date` и совпадает правило повтора.
- Просрочена: `repeat = none`, `date < сегодня`, не выполнена.
- Устаревшие поля (поддерживаются при чтении): `prio` (3 = срочно и важно, 2 = важно), `subs`/`subDone` (старые встроенные подзадачи — мигрированы в отдельные документы).

## 6. Нефункциональные требования

- **Хранение:** облачная база артефакта, синхронизация в реальном времени между устройствами; доступ на чтение и запись — только владелец (и редакторы, если владелец поделится).
- **Резерв:** если база недоступна — локальное хранение в браузере с предупреждением.
- **Загрузка:** если хранилище не ответило за 10 с — сообщение «данные могут быть неактуальны».
- **Адаптивность:** десктоп — две колонки (список | итоги и матрица), до 900 px — одна колонка; телефон 360 px+.
- **Доступность:** кнопки от 44 px, видимый фокус, подписи для экранных дикторов, светлая и тёмная тема.
- **Безопасность:** весь пользовательский текст выводится экранированным.
- **Шрифт:** Golos Text; цвета — индиго (работа), оранжевый (личное), красный (просрочено).

## 7. Техническая реализация

- Одна HTML-страница (HTML + CSS + JS без фреймворков), опубликована как артефакт Claude.
- Возможность `db` с правилом `{ path: "", read: "admin", write: "admin" }`.
- Запись: по одной операции на документ за раз (очередь), `set` для создания и редактирования, `update` для отметок и переноса.
- Напоминания: scheduled task `trig_01XAqn3M3Hm8KReRuukiVEMY`, cron `CRON_TZ=Asia/Qyzylorda 47 8,19 * * *`, читает коллекцию `tasks` через `db_list`.

## 9. Вне рамок MVP / бэклог

- Системные уведомления браузера в конкретное время задачи (сейчас — только push-сводки 2 раза в день и подсветка на странице).
- Настройка времени push-напоминаний из интерфейса.
- Подзадачи у повторяющихся задач.
- Перетаскивание для изменения порядка и перенос подзадачи к другому родителю.
- Поиск по задачам, теги, заметки и вложения.
- Совместная работа (назначение задач другим людям) — для квадранта «Делегировать».
- Экспорт итогов (CSV / отчёт за месяц), история за период длиннее недели.

## 10. Метрики успеха

- Доля дней, когда выполнено ≥ 80% задач дня.
- Число просроченных задач (тренд вниз).
- Длина серии «дней без хвостов».
- Доля выполненных задач квадранта «Сделать сейчас» в срок.
