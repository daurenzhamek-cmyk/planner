# Планировщик задач

Проект по [prd.md](prd.md): рабочие и личные задачи в одном месте, подзадачи до 3 уровней, матрица Эйзенхауэра, итоги дня и недели, текст утренних и вечерних push‑сводок.

## Запуск

Чистые HTML + CSS + JS без фреймворков и без сборки.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\serve.ps1
```

Затем откройте http://localhost:8080/. Сервер нужен потому, что браузер не загружает соседние `.js` у страницы, открытой как файл.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `css/styles.css` | стили: светлая и тёмная тема, адаптивность (до 900 px одна колонка) |
| `js/model.js` | модель данных и правила из PRD §5: повторы, просрочка, квадранты, «на подходе», миграция старых `prio` и `subs`. Без DOM, работает и в Node |
| `js/storage.js` | хранилище: база артефакта Claude (`window.claude.use('db')`, коллекция `tasks`); если её нет — `localStorage` с предупреждением; очередь записи по документу |
| `js/app.js` | интерфейс: форма, режимы «Все задачи» / «По дням», хвосты, матрица, итоги, удаление с «Вернуть», обновление раз в минуту |
| `scripts/summary.js` | текст push‑сводки «План на сегодня» / «Итоги дня» (PRD §4.7) |
| `scripts/serve.ps1` | локальный статический сервер на PowerShell |
| `examples/tasks.sample.json` | пример данных для проверки |

## Данные

- **Локально** задачи хранятся в `localStorage` браузера (ключ `planner-tasks`).
- **Как артефакт Claude** та же страница использует облачную базу с правилом `{ path: "", read: "admin", write: "admin" }`, если она доступна.
- Кнопки **«Экспорт JSON» / «Импорт JSON»** нужны для резервной копии и для скрипта сводок.

## Push‑сводки

```powershell
node scripts/summary.js morning tasks.json
```

```powershell
node scripts/summary.js evening tasks.json
```

Скрипт только читает задачи. Часовой пояс — `Asia/Qyzylorda`, его можно сменить через `PLANNER_TZ`. В облачной версии эти тексты по расписанию `CRON_TZ=Asia/Qyzylorda 47 8,19 * * *` присылает scheduled task. Локально скрипт печатает текст, а саму отправку на телефон нужно подключить отдельно. Для скрипта нужен Node.js.
